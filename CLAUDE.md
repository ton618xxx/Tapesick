# Tapesick — заметки для Claude

Хоррор-проект на Unreal Engine. Папка называется UE_5.7, но **редактор — UE 5.8** (F:/Epic Games/UE_5.8). Основной уровень: `Content/Levels/L_Room_Main.umap` (дом Джорджа + улица в стиле Ливерпуля). GPU: RTX 3070, Nanite поддерживается.

## Пользователь

Новичок в UE, общается по-русски. Инструкции по редактору давать «для новичка»: каждая кнопка/панель/поле по имени, этапы отдельными сообщениями, не перескакивать.

## Железные правила

1. **Компилировать модуль Tapesick ДО открытия редактора** (после pull/смены ветки/чистки Binaries). Если в редакторе ошибка `Failed to load ... as Parent` у BP_TapesickGameMode — **НЕ сохранять и не коммитить**: закрыть без сохранения, пересобрать, переоткрыть.
2. Для блокаутов брать `/Game/Meshes/SM_Cube_Nanite` / `SM_Plane_Nanite`, НЕ engine BasicShapes (VSM overflow). Плоским подложкам и лампочкам выключать Cast Shadow.
3. Правки материалов/графов через unreal-mcp — строго по одному вызову за раз (параллельные вызовы роняли редактор), сохранять после каждого этапа и проверять файл на диске.
4. `ActorTools.set_actor_transform` сбрасывает незаданные поля (location/rotation/scale) — всегда передавать трансформ целиком.
5. Если FPS обвалился — сначала проверить открытые вьюпорты (wireframe обходит Nanite), потом уже трогать настройки.
